# Ostean (v_final)

Ostean is pronounced **Oste-AN**.

```text
npx create-ostean@latest project-name --lang=ts
ostean init project-name --lang=ts
ostean check
ostean test
```

This package bundles the standalone Windows x64 verifier and scaffolder.
Its dispatcher verifies the executable checksum and preserves native exit codes.
It has no runtime dependencies or installation hooks.
Unsupported platforms fail explicitly. Native commands require no Node interpreter;
the npm dispatcher itself requires the exact Node version in package.json.

The TypeScript socket emits ostean.json, strict compiler settings, the mirrored
architectural constitution, six boundary rulebooks, canonical registries,
mockable services, a presentation corridor, and public/private tests.

Check exits: 0 verified; 1 confirmed violation; 2 unverifiable construct.
Verification covers project source within the supported TypeScript subset,
conditional on the exact external trust boundary declared in ostean.json.
The protected private harness counts 128 seeded executions across four categories.

Local archive use before publication:

```text
npm exec --offline --package ./create-ostean-1.0.0.tgz -- create-ostean project-name
```

The default project name is ostean-app. Existing destinations are never overwritten.
Badge standard: **Ostean Verified — Athletic Codebase**.
